## Build Failure Fix

Build failed in:

```text
src/pages/assets/notes/[slug].astro
```

Error:

```text
extractOutlineItems is not defined
```

Cause:

`getStaticPaths()` called `extractOutlineItems()`, but the helper function was not available in the generated build module.

Fix:

Moved the related helper functions into `getStaticPaths()`:

- `stripHtml`
- `decodeHtml`
- `extractOutlineItems`

Result:

```bash
npm run build
```

Build completed successfully.
